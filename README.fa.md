# پَـــــرنا | سامانه‌ی هوشمند پردازش نامه‌ها

**پَرنا** یک برنامه‌ی دسکتاپ ویندوزی برای مشاهده و پردازش نامه‌های کارتابل است. برنامه با `Selenium` به سامانه متصل می‌شود، محتوای نامه‌ها را استخراج می‌کند و با استفاده از مدل `qwen3.5:latest` از طریق `Ollama`، خلاصه‌ی نامه و مهلت انجام کار را به‌صورت محلی تولید می‌کند.

متن نامه‌ها برای تحلیل هوش مصنوعی به سرویس ابری ارسال نمی‌شود. اتصال اینترنت برای ورود به سامانه و دریافت اولیه‌ی مدل هوش مصنوعی لازم است.

---

## قابلیت‌ها

- **استخراج اطلاعات نامه‌ها:** نمایش اطلاعات و نتایج استخراج‌شده‌ی نامه‌ها از جدول کارتابل.
- **مرتب‌سازی انعطاف‌پذیر:** مرتب‌سازی جدول بر اساس تاریخ نامه یا ددلاین از طریق منوی مرتب‌سازی.
- **تنظیم خودکار اندازه‌ی ستون‌ها:** تنظیم اندازه‌ی اولیه‌ی ستون‌ها متناسب با فضای صفحه، با امکان تغییر دستی.
- **نمایش پیشرفت پردازش:** نمایش پیشرفت بر اساس مراحل واقعی پردازش و رنگ‌بندی ددلاین‌های گذشته و نزدیک.
- **جست‌وجوی لحظه‌ای:** جست‌وجو در تمام ستون‌های جدول به‌صورت لحظه‌ای.
- **مدیریت دستورات ارجاع:** ثبت، ویرایش و حذف دستور ارجاع برای هر نامه.
- **توقف پردازش:** امکان متوقف‌کردن پردازش در حال اجرا.
- **تشخیص ناسازگاری ChromeDriver:** تشخیص ناسازگاری نسخه‌ی `ChromeDriver` با `Chrome` و نمایش راهنمای دریافت نسخه‌ی سازگار.
- **مدیریت خطاهای شبکه:** نمایش خطاهای شبکه و امکان تلاش مجدد.
- **استخراج متن PDF:** استخراج متن فایل‌های `PDF` از لایه‌ی متنی `PDF.js`.
- **تشخیص متن تصاویر:** تشخیص متن تصاویر `JPG` با استفاده از `Tesseract OCR` و داده‌های زبانی فارسی و انگلیسی.
- **خلاصه‌سازی هوشمند:** تولید خلاصه‌ی نامه‌ها به‌صورت محلی با مدل `qwen3.5:latest` از طریق `Ollama`.
- **تشخیص ددلاین:** شناسایی مهلت انجام کار از محتوای نامه‌ها.
- **ذخیره‌سازی محلی اطلاعات:** نگهداری سوابق نامه‌های پردازش‌شده و خروجی‌های برنامه در فایل‌های محلی.
- **خروجی Excel و PDF:** دریافت خروجی از جدول و نتایج پردازش در قالب فایل‌های Excel و PDF.

## مرتب‌سازی و نمایش ددلاین‌ها

در منوی مرتب‌سازی، گزینه‌های زیر در دسترس هستند:

- ترتیب پیش‌فرض نمایش
- تاریخ نامه از جدید به قدیم یا از قدیم به جدید
- ددلاین از زودترین به دیرترین یا از دیرترین به زودترین

تاریخ‌های خالی یا نامعتبر در انتهای جدول قرار می‌گیرند. مرتب‌سازی فقط ترتیب نمایش را تغییر می‌دهد و اطلاعات ذخیره‌شده‌ی نامه‌ها را تغییر نمی‌دهد.

ددلاین‌های گذشته با رنگ قرمز و ددلاین‌های امروز تا سه روز آینده با رنگ زرد نمایش داده می‌شوند.

## پیش‌نیازها

- سیستم‌عامل ویندوز
- `Python 3.11` به‌عنوان نسخه‌ی پیشنهادی برای اجرای کد منبع
- `Google Chrome` و نسخه‌ی سازگار `ChromeDriver`
- `Tesseract OCR` و داده‌های زبانی فارسی و انگلیسی برای اجرای کد منبع
- `Ollama` و مدل `qwen3.5:latest` برای خلاصه‌سازی هوشمند و تشخیص ددلاین

در نسخه‌ی اجرایی مستقل فعلی، موتور `Tesseract OCR` و داده‌های زبانی فارسی و انگلیسی همراه فایل برنامه قرار دارند؛ بنابراین برای استفاده از این نسخه نیازی به نصب جداگانه‌ی آن‌ها نیست.

### وابستگی‌های خارجی

ابزارهای اجرایی و فایل‌های جانبی مانند `ChromeDriver`، فایل آیکون `icon.ico`، داده‌های زبانی OCR و نصب‌کننده‌ی Ollama در مخزن Git نگهداری نمی‌شوند. برای اجرای کد منبع، فایل‌های موردنیاز را جداگانه تهیه کنید و در ساختار زیر قرار دهید:

```text
project/
├── chromedriver.exe
├── icon.ico
├── ocr/
│   ├── tesseract.exe
│   └── tessdata/
│       ├── fas.traineddata
│       └── eng.traineddata
└── ai/
    └── ollama/
        └── OllamaSetup.exe
```

برای اجرای کد منبع، فایل `chromedriver.exe`، فایل `icon.ico` و پوشه‌ی `ocr` باید در ریشه‌ی پروژه قرار داشته باشند.

نصب‌کننده‌ی Ollama فقط زمانی لازم است که این ابزار از قبل روی سیستم نصب نشده باشد. برای استفاده از قابلیت‌های هوش مصنوعی، خود Ollama و مدل موردنیاز باید در دسترس باشند.

## نصب و اجرای کد منبع

در `PowerShell` و از ریشه‌ی پروژه، مراحل زیر را انجام دهید.

### ۱. ایجاد محیط مجازی

```powershell
python -m venv .venv
```

### ۲. فعال‌سازی محیط مجازی

```powershell
.\.venv\Scripts\Activate.ps1
```

### ۳. به‌روزرسانی pip

```powershell
python -m pip install --upgrade pip
```

### ۴. نصب کتابخانه‌های پروژه

```powershell
python -m pip install -r requirements.txt
```

### ۵. اجرای برنامه

```powershell
python PyQt.py
```

پس از بازشدن Chrome، وارد سامانه‌ی مدیریت نامه‌ها شوید و به صفحه‌ی نامه‌های دریافتی یا کارتابل بروید. نشانی‌های ورود و کارتابل در فایل `config.py` تنظیم شده‌اند.

## راه‌اندازی هوش مصنوعی با Ollama

پَرنا برای تولید خلاصه‌ی نامه‌ها و تشخیص مهلت انجام کار از مدل `qwen3.5:latest` از طریق `Ollama` استفاده می‌کند.

پس از نصب Ollama، اگر مدل از قبل دریافت نشده است، دستور زیر را اجرا کنید:

```powershell
ollama pull qwen3.5:latest
```

دریافت اولیه‌ی مدل به اتصال اینترنت نیاز دارد. پس از دریافت مدل و آماده‌شدن سرویس Ollama، پردازش هوش مصنوعی می‌تواند به‌صورت محلی انجام شود و متن نامه‌ها برای این تحلیل به سرویس هوش مصنوعی ابری ارسال نمی‌شود.

---

## ساخت فایل اجرایی ویندوز

پس از فعال‌کردن محیط مجازی و نصب وابستگی‌های موجود در `requirements.txt`، اسکریپت ساخت را اجرا کنید:

```powershell
.\installer\build.bat
```

تنظیمات ساخت در فایل `پَـــــرنا.spec` قرار دارد.

فایل اجرایی ساخته‌شده در پوشه‌ی `dist/` قرار می‌گیرد و فایل‌های موقت فرایند ساخت در پوشه‌ی `build/` ذخیره می‌شوند.

### اجرای نسخه‌ی مستقل

نسخه‌ی مستقل `پَـــــرنا.exe` شامل موتور `Tesseract OCR` و داده‌های زبانی فارسی و انگلیسی است؛ بنابراین به پوشه‌ی جداگانه‌ی `ocr` نیازی ندارد.

پیش از اجرای برنامه، فایل `chromedriver.exe` را در کنار فایل اجرایی قرار دهید.

برای نمایش آیکون برنامه در Taskbar، فایل `icon.ico` باید در کنار فایل `پَـــــرنا.exe` قرار داشته باشد.

برای استفاده از قابلیت‌های خلاصه‌سازی هوشمند و تشخیص ددلاین، Ollama باید نصب شده باشد و مدل موردنیاز در دسترس باشد.
